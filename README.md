# gt-isye

Georgia Tech ISyE research — MARTA Reach pilot work.

## marta-reach/

Python + Excel exercise built on the MARTA Reach on-demand transit pilot
(West Atlanta / Belvedere Park / Fort Gillem). Synthetic ride-request data
shaped like the real pilot: analyze it, find peak demand, write a scheduling
recommendation.

- `marta-reach-rides.xlsx` — 700 ride requests, one week
- `marta-exercise.py` — 5 questions; run top to bottom

Setup: `pip install pandas openpyxl`
